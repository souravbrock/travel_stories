# Android app (Capacitor shell around the live site)

The site is server-rendered PHP, so the Android app is a native WebView shell
pointing at `https://tstory.reddevils.co.in` (no separate codebase).

## Project location (build machine)

`C:\Users\soura\tstory-android` (kept outside the web repo on purpose).

```
tstory-android/
  capacitor.config.json   appId com.reddevils.tstory, server.url = live site
  www/index.html          offline fallback page (bundled, shown without net)
  android/                native project (generated by `npx cap add android`)
```

## Prereqs (one-time, Windows)

1. JDK 21: `winget install EclipseAdoptium.Temurin.21.JDK` (Capacitor 7.4+
   targets Java 21)
2. Android cmdline-tools → `C:\Android\Sdk\cmdline-tools\latest`
3. `sdkmanager "platform-tools" "platforms;android-35" "build-tools;35.0.0"`
4. Env: `JAVA_HOME=<jdk21>`, `ANDROID_SDK_ROOT=C:\Android\Sdk`

## Rebuild the APK

```powershell
cd C:\Users\soura\tstory-android
npx cap sync android
cd android
.\gradlew.bat assembleDebug
# APK: android\app\build\outputs\apk\debug\app-debug.apk
```

Install directly on a phone (USB/file transfer) or share via Drive. For Play
Store later: `assembleRelease` + sign with your keystore + AAB.

## Notes

- Debug APK is auto-signed; release needs your own keystore (`keytool -genkey`).
- Pure WebView apps may face Play review scrutiny — add push/offline before
  store submission if needed. Direct distribution is unaffected.
